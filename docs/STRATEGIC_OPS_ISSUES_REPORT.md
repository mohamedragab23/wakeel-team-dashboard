### 2. الأيام الناقصة في Google Sheet تشوّه الأرقام (Critical Priority)

**الموقع:** `lib/strategicOps/talabatOpsMetrics.ts` السطر 201

**المشكلة:**
```typescript
const actualHours = avg(dailySeries.map((d) => d.hours));
```

يتم حساب متوسط الساعات اليومية بقسمة على **جميع أيام التقويم** حتى لو لم تُرفع بيانات عنها.

**مثال توضيحي:**
| السيناريو | الإجمالي | أيام التقويم | أيام البيانات | الحساب الحالي | الحساب الصحيح |
|-----------|----------|--------------|---------------|----------------|----------------|
| الفترة المختارة: 7 أيام | 12,000 ساعة | 7 أيام | 5 أيام مرفوعة | 12,000 ÷ 7 = **1,714 س/يوم** | 12,000 ÷ 5 = **2,400 س/يوم** |

**التأثير:**
- ❌ متوسط الساعات اليومية يظهر أقل من الواقع
- ❌ نسبة تحقيق الهدف Achievement تظهر منخفضة بشكل خاطئ
- ❌ فجوة الساعات Hours Gap تظهر أكبر من الحقيقة

**الحل المقترح:**
```typescript
// بدلاً من:
const actualHours = avg(dailySeries.map((d) => d.hours));

// استخدم:
const operationalDays = dailySeries.filter((d) => d.hours > 0 || d.scheduledRiders > 0);
const actualHours = operationalDays.length > 0 
  ? avg(operationalDays.map((d) => d.hours))
  : 0;
```

### 5. متوسط ساعات الطيار النشط يخفي المشكلة (High Priority)

**الموقع:** `lib/strategicOps/talabatOpsMetrics.ts` السطر 203

**المشكلة:**
```typescript
const avgHoursPerActiveRider = activeRiders > 0 ? round2(actualHours / activeRiders) : 0;
```

**السيناريو:**
- إذا كان `actualHours` منخفضاً بسبب أيام ناقصة = 1,714 س/يوم
- و `activeRiders` أيضاً منخفض بسبب نفس السبب = 180 طيار
- النتيجة: `1,714 ÷ 180 = 9.5 ساعة/طيار` — يبدو جيداً! ❌

**لكن الواقع:**
- `actualHours` الصحيح = 2,400 س/يوم
- `activeRiders` الصحيح = 200 طيار
- النتيجة الصحيحة: `2,400 ÷ 200 = 12 ساعة/طيار` — أفضل! ✅

**التأثير:**
- ❌ الرقم المنخفض يُخفي الأداء الفعلي
- ❌ قد تتخذ قرارات خاطئة بناءً على رقم مضلل

### 6. نسبة تحقيق الهدف Achievement خاطئة (Critical Priority)

**الموقع:** `lib/strategicOps/talabatOpsMetrics.ts` السطر 205

**المشكلة:**
```typescript
const achievementPercent = pct(actualHours, targetHours);
```

**مثال:**
- الهدف: 2,200 ساعة/يوم
- `actualHours` المحسوب خطأ: 1,714 س/يوم
- النتيجة: `(1,714 ÷ 2,200) × 100 = 78%` — فشل! ❌

**لكن الواقع:**
- `actualHours` الصحيح: 2,400 س/يوم
- النتيجة الصحيحة: `(2,400 ÷ 2,200) × 100 = 109%` — نجاح! ✅
